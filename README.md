# Lua Password Generator - A Programming Challenge

I programmed this password generation algorithm as a challenge to try to learn Lua, due to its well known easy learning level.

Despite not knowing the language at all, I managed to:

- ⌨️ Create basic **CLI (Command Line Interface)**
- 🔀 Use control flow to **iterate ASCII data**
- 🛡️ **Use actual international cybersecurity standards (NIST/OWASP)** for my code
- 🧮 Create a random choice **password generation function**

## How to Use the Project?

To run this project, download the code and upload it to **an IDE or code editor** such as:

- VSCode
- OneCompiler
- myCompiler
- Tutorials Point
  
and click any **Run/Play button (▶)** found in that environment.
